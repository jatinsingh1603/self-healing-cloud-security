Self-Healing
Cloud Security

An AI-driven closed loop that detects AWS misconfigurations, decides on an approved fix, applies it through a least-privilege identity and verifies the result with an independent re-check. Evaluated on three public, deliberately vulnerable AWS datasets.

04 - Methodology

Architecture

Three identities, one registry, one loop. The component that judges "healed" can never change the resource it judges, and the component that changes resources can only call the API actions its approved tools need.

05 - Code

Run it yourself

git clone __REPO__
cd self-healing-cloud-security
pip install -r requirements.txt

python -m selfheal demo             # 3 deck scenarios + extras
python -m selfheal demo --approve   # approve the HIGH-risk IAM fix
python -m pytest -q                 # 11 tests

bash experiments/get_datasets.sh    # clone the 3 public datasets
python experiments/run_all.py       # all experiments -> results/
python experiments/make_charts.py   # graphs for the deck
